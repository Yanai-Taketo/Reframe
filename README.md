# Reframe — ビフォー・アフター写真比較ツール

施術前(ビフォー)と施術後(アフター)の写真を同じ構図で撮影し、並べて比較して1枚の画像に書き出すツールです。ブラウザで動くPWA(ホーム画面に追加してアプリのように使える仕組み)で、iPhone / iPad / Android / PC(Chrome)で動作します。

写真と設定はすべて使っている端末の中だけに保存され、サーバーには送られません。

ソースコード: https://github.com/Yanai-Taketo/reframe

## 構成ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `styles.css` | 見た目(色・文字・配置) |
| `js/app.js` | 画面の動作 |
| `js/camera.js` | カメラ、輪郭線、水平器、ガイド線 |
| `js/compare.js` | 比較表示、注釈、書き出し画像の生成、位置合わせ |
| `js/store.js` | 設定の保存、ビフォー写真の一時保持、画像処理、共有 |
| `sw.js` | オフライン動作用のキャッシュ |
| `manifest.webmanifest` | ホーム画面追加用の情報 |
| `icons/` | アプリアイコン |
| `.nojekyll` | GitHub Pagesの設定用(空ファイル) |

## GitHub Pagesに置く

1. GitHubにログインし、新しいリポジトリを作る(例: `reframe`)。公開(Public)で作成する。
2. 上のファイルを、フォルダ構成そのままでリポジトリの直下にアップロードする(`index.html` がリポジトリのトップに来るようにする)。
3. リポジトリの「Settings」→「Pages」を開き、「Build and deployment」の「Source」を「Deploy from a branch」、Branchを `main` と `/ (root)` にして保存する。
4. 数分待つと、同じ画面に `https://<ユーザー名>.github.io/reframe/` のようなURLが表示される。これがアプリのURL。
5. 端末のブラウザでそのURLを開き、カメラの使用を「許可」する。

リポジトリを公開にするとコードは誰でも見られますが、写真や設定はリポジトリには入らず、各端末の中にしか置かれません。

## ホーム画面に追加する

- iPhone / iPad(Safari): 共有ボタン →「ホーム画面に追加」
- Android(Chrome): メニュー(︙)→「ホーム画面に追加」または「アプリをインストール」
- PC(Chrome): アドレスバー右端のインストールアイコン

追加後は、ホーム画面のアイコンから起動すると全画面で動き、一度開いたあとは通信がなくても起動できます。

## 使い方

1. ホームで「ビフォーを撮る」。プリセット(全身・顔など)を選び、ガイド線に体を合わせて撮影する。
2. 撮影後の画面で「端末に保存」を押すと、共有シートから写真アプリなどに保存できる。撮った写真はアプリ内にも一時保持され、ホームの「最近のビフォー」に並ぶ。
3. 施術後、ホームで「アフターを撮る」。ビフォーを選ぶと、その写真が半透明でカメラ映像に重なるので、同じ位置・大きさに合わせて撮影する。「輪郭」に切り替えると線だけの重ねになり、合わせやすい。
4. 撮影後、「位置合わせ」でアフターの位置・大きさ・回転を微調整できる。
5. 「比較へ」で比較画面に移る。左右・上下・重ね・スライド・切替の5つの見方があり、2枚は同時に拡大・移動できる。横線・縦線・角度の注釈、顔などのぼかしも入れられる。比較に使ったビフォーは一時保持から自動で削除される(設定で変えられる)。
6. 右上の共有ボタンから、ラベルと院名・ロゴ入りの1枚画像を作り、共有シートで保存または送信する。

ホームの「端末の写真で比較」からは、過去に保存した2枚を選んで同じ比較ができます。

設定画面では、院名とロゴ、プリセット(縦横比・ガイド線)、連続撮影(正面→側面→背面などを順番に撮る)、一時保持の期間(残さない / 当日 / 7日 / 30日)と比較後の自動削除を変えられます。

撮影画面の「水平器」を押すと、画面中央に水平の線が出ます。端末が傾くと中央の線が傾き、水平になると線がつながって黄色になります。

## 作成した画像の識別

Reframeで撮影した写真と書き出した比較画像には、次の情報をメタデータとして記録します。

- 作成ソフト(`Reframe 1.5.0` のようにバージョン付き。カメラのメーカー・機種の欄にも `Reframe` と種類を入れています)
- 作成日時とタイムゾーン
- 画像ごとのID(32桁の乱数)
- 内容(ビフォー/アフター/比較の別、プリセット、ラベル)

JPEGはEXIFとXMP、PNGはテキストチャンクに書き込むので、写真アプリの情報表示や一般的なメタデータ表示ツールで読めます。利用者や端末を特定する情報は含みません。

LINEやSNSに送った画像やスクリーンショットでは、メタデータが削除されます。メタデータは誰が作ったかを示す「表示」であり、改ざんされていないことの証明ではありません。

## 更新する

ファイルを差し替えるときは、次の3か所を上げてからアップロードします。

- `sw.js` の `VERSION`
- `js/store.js` の `APP_VERSION`(表示用)と `APP_BUILD`(メタデータに入れるビルド番号。リリースごとに1ずつ増やす)

利用中の端末では、次にアプリを開いたときに「新しいバージョンがあります」と表示されるので「再読み込み」を押します。表示されない場合は設定画面の「更新を確認」を押すか、ブラウザを完全に閉じて開き直してください。

## 写真と設定の扱い

- ビフォー写真の一時保持は、端末内のブラウザ領域(IndexedDB)に置かれ、設定した期間を過ぎると自動で削除されます。残したい写真は「端末に保存」で写真アプリなどに保存してください。
- 院名・ロゴ・プリセットなどの設定は、端末内のブラウザ領域(localStorage)に保存されます。
- ブラウザの「サイトデータを削除」や「履歴を消去」を行うと、これらはすべて消えます。
- 共有シートで送った先(LINE、メールなど)の扱いは、送った先のアプリに従います。

## うまく動かないとき

- カメラが起動しない: URLが `https://` で始まっているか確認する。ブラウザの設定(サイトの権限)と端末の設定でカメラが「許可」になっているか確認する。iPhoneでホーム画面のアイコンから起動した場合に映像が出ないときは、Safariで同じURLを開いて使う。
- 「端末に保存」で写真アプリに入らない: iPhoneは共有シートの「画像を保存」を選ぶ。Androidとパソコンではダウンロードフォルダに保存される。
- 一時保持の写真が消えていた: 設定した保持期間を過ぎたか、ブラウザのデータが削除されています。大切な写真は端末に保存してください。
- 更新が反映されない: 上の「更新する」の手順を確認し、`sw.js` の `VERSION` が変わっているか確かめる。
- 傾きセンサー(水平器)が使えない: iPhone / iPadでは「水平器」ボタンを押したときに出る確認で「許可」を選ぶ。パソコンにはセンサーがないため使えません。
